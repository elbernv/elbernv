# Hi, I'm Elber 👋

**Full-stack engineer who ships and runs what I build.**
TypeScript & Python · NestJS · React / Angular · Docker · Linux · AI-native workflow

5 years building production systems end to end: identity, APIs, databases, frontends, the CI/CD pipeline and the Linux server they run on. Based in Venezuela 🇻🇪, open to remote work.

---

### 🏗️ Selected work

Most of my work lives in private client repositories, so here's what those systems do.

- **Travel agency platform.** Single sign-on with Keycloak across the CRM and an internal community app, with custom extensions and federation of existing users. An internal social network built end to end: real-time feeds, push notifications, media and video. On the CRM: payment gateways, bank reconciliation and supplier integrations.
- **Accounting review platform.** Uploaded balance sheets automatically generate each period's reviews, which then go through a multi-level approval flow. Includes 2FA and Excel processing.
- **Clinic management system.** Built solo, from the API to the dashboard: patients, treatments, sessions, scheduling and media storage.
- **B2B partner portal.** API for business partners with PDF document generation, Excel reporting and caching.

### 🤖 AI-assisted engineering

I use AI as an engineering tool, not an autopilot. Every project I work on has its own setup: custom skills and MCP integrations tailored to its business logic, and strict rules that define what the agent can and can't do. That means faster delivery while I keep control of the architecture, the code quality and what reaches production.

### ⚙️ Infra & DevOps

I set up, deploy and run systems in production: Linux VPS administration and hardening, Nginx, Docker services, process management, CI/CD pipelines and separate dev and prod environments. I can own a system from the first commit to keeping it healthy in production.
