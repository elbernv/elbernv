# Hola, soy Elber 👋

**Ingeniero full-stack que despliega y opera lo que construye.**
TypeScript & Python · NestJS · React / Angular · Docker · Linux · Flujo de trabajo con IA

5 años construyendo sistemas en producción de punta a punta: identidad, APIs, bases de datos, frontends, el pipeline de CI/CD y el servidor Linux donde corren. Desde Venezuela 🇻🇪, abierto a trabajo remoto.

---

### 🏗️ Trabajo destacado

Casi todo mi trabajo está en repositorios privados de clientes, así que en lugar de enlaces cuento qué hacen esos sistemas.

- **Plataforma para una agencia de viajes.** Single sign-on con Keycloak para el CRM y una app interna de comunidad, con extensiones propias y federación de los usuarios existentes. Una red social interna construida de punta a punta: feeds en tiempo real, notificaciones push, archivos y video. En el CRM: pasarelas de pago, conciliación bancaria e integraciones con proveedores.
- **Plataforma de revisión contable.** Al subir un balance se generan automáticamente las revisiones del periodo, que luego pasan por un flujo de aprobación de varios niveles. Incluye 2FA y procesamiento de Excel.
- **Sistema de gestión para una clínica.** Construido por mí solo, de la API al panel: pacientes, tratamientos, sesiones, agenda y almacenamiento de archivos.
- **Portal B2B para socios.** API para socios comerciales con generación de documentos PDF, reportes en Excel y caché.

### 🤖 Ingeniería asistida por IA

Uso la IA como herramienta de ingeniería, no como piloto automático. Cada proyecto en el que trabajo tiene su propia configuración: skills personalizadas e integraciones MCP adaptadas a su lógica de negocio, y reglas estrictas que definen qué puede hacer el agente y qué no. Así entrego más rápido y sigo controlando la arquitectura, la calidad del código y lo que llega a producción.

### ⚙️ Infra y DevOps

Monto, despliego y opero sistemas en producción: administración y hardening de VPS Linux, Nginx, servicios con Docker, gestión de procesos, pipelines de CI/CD y ambientes separados de desarrollo y producción. Puedo hacerme cargo de un sistema desde el primer commit hasta mantenerlo sano en producción.
